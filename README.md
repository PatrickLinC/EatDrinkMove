# 卡路里大作戰 CALORIE WARS

記錄**吃**（飲食）、**喝**（喝水）、**動**（運動）的 iPhone + Apple Watch App，做成 8-bit 像素遊戲的樣子：
記錄就是冒險，每一餐都會收進食物圖鑑，記錄越多角色等級越高。拍照就能讓 AI 估算熱量，而且會在對的時間提醒你記錄。

（專案資料夾與程式內部名稱是 `EatDrinkMove`。）

## 畫面

全部使用像素字體（俐方體 11 號）、像素邊框的遊戲視窗與格子進度條。底部導覽列：**今日**／**營地**／**足跡**／**圖鑑**／**戰績**／**角色**

- **今日**：左右箭頭切換日期；點中間的日期打開**紅綠燈月曆**（每天的目標達成率：30% 以下紅、90% 以下黃、90% 以上綠），點一天就跳過去
  - **狀態**：頭像、等級與經驗值，熱量／喝水／步數／燃燒的格子血條（燃燒對照每日建議運動消耗，超過就滿格、數字繼續跑），還可以吃多少，三大營養素、鈉、糖
  - **指令**：吃東西、喝水、運動、量體重
  - **任務**：「午餐還沒記錄！」（拍照／同昨天／沒吃）、喝水進度落後、連接 Apple 健康
  - **水壺**：一排像素水杯，點一下喝一杯，點最後一杯可以復原
  - **冒險日誌**：依早餐、午餐、點心、晚餐、宵夜、運動分段，每段可以直接「＋」新增，點一項可以修改
- **吃東西**：拍照辨識、相簿、營養標示、條碼、搜尋、用說的或打字描述
- **營地**：精靈在營地散步，用元氣幣蓋建築、看羈絆故事和稱號
- **足跡**：今日足跡地圖、出發冒險、冒險統計、最近的路線、世界迷霧
- **圖鑑**：分成精靈、地圖、食物三頁。食物頁的每種吃過的食物都有編號（No.001…）與像素圖，可依編號／最常吃／最近排序；收集進度與獎盃
- **戰績**：每日目標、AI 軍師（最近 7 天的健康建議）、週報（熱量、喝水、步數、運動、鈉、體重的像素長條圖，可切換週）
- **AI 小夥伴**：像素飯糰精靈「小卡」浮在畫面上（可以拖曳、長按隱藏），偶爾冒泡提醒；點它就能聊天，它知道你今天吃了什麼、喝了多少、走了幾步。回話風格可選火爆、激勵、毒舌、嫌棄、戀愛，或只會叫的貓咪、小狗、小鳥；造型有飯糰精靈、珍奶精靈、小籠包、荷包蛋、哥布林、水滴史萊姆、貓咪、小狗（黃金獵犬）、小鳥，也可以用任何動物、職業、食物 emoji
- **角色**：角色卡（頭像、等級、稱號、身高體重 BMI）；個人資料、每日目標、偏好設定（三套配色）、提醒、AI、健康計算機、權限與同步

## 功能

**記錄飲食**
- 搜尋頁分成「全部／近期／收藏／自訂」，選好的食物排在下方托盤，按「送出」一次存起來
- 拍照 → 可以先打字或**用說的**補充照片看不出來的事（例如「飯只吃半碗」「雞腿去皮」「半糖」），再讓 AI 辨識每一樣食物，估算熱量、蛋白質、碳水、脂肪、糖、鈉
  - 預設用 **iPhone 內建的 Apple AI**：免費、不用網路、照片不離開手機，營養數值盡量對照台灣食品營養資料庫
  - 覺得不準可以按「用 Gemini 再算一次」；Apple AI 不能用時自動改用 Gemini（免費額度），也可以改用 Claude
- **讀營養標示**：讀出每一份量、本包裝幾份、每份的營養，再選「半份／1 份／整包／自訂公克」自動換算；讀過的商品會記住
- 用說的或打字描述（例如「一碗牛肉麵加燙青菜」）→ AI 估算
- 掃商品條碼（Open Food Facts）
- 內建衛福部食藥署**台灣食品營養成分資料庫**（2,180 種食物，可離線搜尋、可用俗名找）
- 長按食物加入收藏；「自訂」可以建立家裡常煮的菜
- 「同昨天」一鍵重複昨天的早餐
- AI 認錯或份量不對，點背包裡的食物直接改，還有「吃一半」「×1.5」快速調整

**元氣大陸冒險**（詳細設計見 [ROADMAP.md](ROADMAP.md)）
- **精靈收集**：九個區域 27 隻精靈，靠步數、睡眠、喝水、一分鐘呼吸、出發冒險和世界迷霧喚醒，每隻都有更難拿到的閃光版；喚醒後可以換成懸浮夥伴，手錶上也看得到
- **節慶活動**：過年、端午、夏日祭、中秋、萬聖節、聖誕節，活動期間做到健康習慣就能喚醒節慶精靈，營地可以蓋限定裝飾；錯過了隔年還會再來
- **一天的節奏**：起床夢境結算（睡眠分數、作息類型）、睡前營火、今日事件；健康的行為會得到元氣幣（每種來源都有上限，沒做到不懲罰）
- **大陸地圖**：累計步行距離在像素大陸上前進，沿路有旅途見聞和主線故事（第一章到王城 80 公里，第二章「迷霧的源頭」到開拓區 185 公里）
- **每日任務與頭目戰**：喝水、步數、睡眠、飲食各有最低標和理想標；週末依這週最弱的習慣決定頭目，週日每週回顧，冒險編年史可以存圖
- **精神力**：讀手錶的 HRV 算出 MP 條，一分鐘呼吸練習會寫進「健康」的正念分鐘
- **足跡**：iPhone 或手錶「出發冒險」記錄散步、跑步路線並存進「健康」，記錄時鎖定畫面和動態島會顯示時間、距離、配速；每條路線可以存成路線圖（地圖卡、照片卡、夜間卡、透明貼圖等，1080 × 1920）或匯出 GPX；走路時拍的照片會貼在路線上；常走的路線會自動比較「比上次快幾秒」；冒險統計有每週距離、連續週數和個人紀錄；**世界迷霧**約 44 公尺一格，平常走動就會在背景解除（需要「永遠」定位權限），也能用照片拍攝地點或 GPX 檔補回以前的足跡，所有位置只存在手機

**食物像素圖與圖鑑**
- 拍照的餐點會在手機上自動去背，再縮成 8-bit 像素圖（用 iOS 內建功能，免費、照片不上傳）
- 沒拍照的食物自動配 emoji，一樣轉成像素圖
- 每一項都可以自己換圖示：從 Apple 所有食物與飲料 emoji 裡挑，有照片的也能改回照片
- 頭像可以選勇者職業、各行各業、運動員、動物夥伴，以及所有食物 emoji
- 「圖鑑」分頁收集每一種吃過的食物，記錄筆數達標會解鎖獎盃

**會記得提醒你**
- 三餐提醒：已記錄的餐不會再響
- 喝水提醒：剛喝過會跳過下一次，喝到目標就停止
- 睡前回顧：告訴你今天還漏了哪一餐
- 通知上直接按「喝了 250 ml」「拍照記錄」「這餐沒吃」「30 分鐘後再提醒」
- 手機上鎖時通知會轉到 Apple Watch，在手錶上按也有效
- 首頁會主動提示「午餐吃了嗎？」「喝水進度落後」
- Siri：「用卡路里大作戰記錄喝水」、「用卡路里大作戰拍照記錄」（也能設定成動作按鈕）

**Apple Watch 與「健康」**
- 讀取手錶的步數、活動熱量、運動分鐘、體能訓練、體重
- 飲食、喝水、體重寫回「健康」App
- 手錶 App：小夥伴（跟 iPhone 帶著的精靈同步，點一下摸摸頭）、今日熱量與喝水、一鍵記錄喝水、從常吃食物一鍵記錄、直接在手錶上記錄散步跑步路線

**其他**
- AI 軍師：分析最近 7 天的飲食、喝水、運動，給 3 個明天就做得到的建議；「冒險週報」會在手機上先算好睡眠、步數、精神力、配速之間的關聯，再請 AI 解讀
- 久坐提醒：上班時間每個整點提醒起來動一動，最近一小時已經走了 250 步以上就不吵你
- App 圖示：喚醒精靈後可以把主畫面圖示換成牠
- 每日目標：自己選目標（自動依目標體重／減脂／維持／增肌）與飲食方式（建議、均衡、高蛋白、增肌、低碳），自動算出熱量與三大營養素（Mifflin-St Jeor 公式，可選亞洲人 × 0.95 校正）；剩餘熱量可以把運動消耗加回來
- 健康計算機：BMI（國健署標準）、BMR / TDEE、熱量赤字與預計達標日、營養素分配、體脂率（美國海軍公式）
- 三套 8-bit 配色：奶茶像素（預設）、經典掌機綠、夜間街機；支援深色模式
- 資料備份：「角色 → 資料備份」把紀錄、照片、精靈、營地、路線、世界迷霧和設定打包成一個檔案，存到「檔案」或 iCloud 雲碟；換手機或重裝後可以還原（AI 金鑰不會匯出）

## 安裝步驟（在 Mac 上）

1. **把整個 `EatDrinkMove` 資料夾複製到 Mac。**

2. **安裝 XcodeGen**（用來從 `project.yml` 產生 Xcode 專案）。打開「終端機」：
   ```bash
   brew install xcodegen
   ```
   沒有 Homebrew 的話，先到 https://brew.sh 照指示安裝。

3. **修改 Bundle ID**：用文字編輯器打開 `project.yml`，把
   `APP_BUNDLE_ID: com.example.eatdrinkmove`
   改成你自己的，例如 `com.yourname.eatdrinkmove`（全世界不能重複，只能用英文、數字、點）。

4. **建立金鑰檔並產生專案**（`Secrets.swift` 不在版本庫裡，要先從範本複製一份，金鑰可以留空）：
   ```bash
   cd ~/Desktop/EatDrinkMove
   cp iOS/Secrets.swift.example iOS/Secrets.swift
   xcodegen
   ```
   完成後會出現 `EatDrinkMove.xcodeproj`，雙擊打開。

5. **設定簽署**：在 Xcode 左邊點最上面的專案 → 分別選 `EatDrinkMove` 和 `EatDrinkMoveWatch` 兩個 target →
   **Signing & Capabilities** → Team 選你的 Apple ID（沒有的話按 Add Account 登入）。

6. **iPhone 開啟開發者模式**：iPhone 用線接上 Mac →
   iPhone「設定 › 隱私權與安全性 › 開發者模式」打開並重新開機。

7. **執行**：Xcode 上方選擇 `EatDrinkMove` scheme 和你的 iPhone，按 ⌘R。
   第一次會要求信任：iPhone「設定 › 一般 › VPN 與裝置管理」→ 信任你的開發者帳號。

8. **Apple Watch**：手錶 App 會跟著 iPhone App 一起安裝。沒出現的話，打開 iPhone 的「Watch」App → 往下找到「卡路里大作戰」→ 安裝。
   手錶也要開開發者模式：手錶「設定 › 隱私權與安全性 › 開發者模式」。

### 免費帳號 vs 付費帳號

- **免費 Apple ID**：可以裝到自己的手機，但**每 7 天要接 Mac 重新按一次 ⌘R**（資料不會消失）。
- **Apple Developer Program（每年 99 美元）**：裝一次用一年，可以用 TestFlight 不接線安裝、分享給家人。**不需要上架 App Store。**

## 設定 AI 拍照辨識

App 支援三種 AI，在「角色 › AI 拍照辨識」選擇：

**Apple 內建 AI（預設，免費、離線）**
- 不用任何設定。iPhone 要開啟「設定 › Apple Intelligence 與 Siri」，第一次使用可能要等模型下載完。
- 手機上的模型比較小：它負責認出食物和估計重量，營養數值能在台灣食品營養資料庫找到的就用資料庫計算。
- 辨識完覺得不準，按「不準？用 Gemini 再算一次」（需要 Gemini 金鑰）。Apple AI 不能用或失敗時也會自動改用 Gemini。

**Google Gemini（有免費額度，當備援或主要使用）**
1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 用 Google 帳號登入，按「Create API key」。
   2026 年起新建立的金鑰是 `AQ.Ab` 開頭，這是正常的新格式。
2. 把金鑰放進 App，兩種方式擇一：
   - **寫進程式（裝好就能用）**：在 Mac 上打開 `iOS/Secrets.swift`（從 `Secrets.swift.example` 複製來的），把金鑰貼在 `geminiAPIKey = ""` 的引號中間，再按 ⌘R 安裝。
     這個檔案已列在 `.gitignore`，不會被上傳到 GitHub，**請不要把它分享給別人**。
   - **在手機輸入**：App「角色 › AI 拍照辨識」貼上。手機上輸入的金鑰會優先使用。
3. 預設模型是 **Gemini 3.8 Flash**；想要更快可以改成 **Gemini 3.5 Flash-Lite**。
4. 免費額度有每分鐘、每天的次數限制，一天記錄三餐通常夠用。
   **注意：免費方案送出的照片與文字，Google 可能用來改進產品。** 介意的話可以在 AI Studio 開啟付費方案。

**Anthropic Claude（付費）**
1. 到 [Anthropic Console](https://console.anthropic.com/) 儲值、建立金鑰（`sk-ant-` 開頭），建議設定每月花費上限。
2. 在「角色 › AI 拍照辨識」把「使用」切換成 Claude，貼上金鑰。可選 Claude Opus 5（最準確）或 Claude Sonnet 5（較便宜）。

沒有金鑰也能用：資料庫搜尋、掃條碼、常吃食物、手動輸入都不需要 AI。

## 重要說明

- 已用 Xcode 27 編譯並裝在 iPhone 15 Pro（iOS 27）上測試。
- 主體去背在**模擬器上不會運作**，會自動改用圓形裁切；請用實機測試。
- 語音輸入需要允許麥克風與語音辨識；手機支援時會在手機上辨識，不上傳。
- 條碼掃描需要 iPhone XS 以後的機型。
- 熱量與營養素都是估算值，僅供參考，不能取代醫師或營養師的建議。

## 資料來源與授權

- 衛生福利部食品藥物管理署「食品營養成分資料集」— 政府資料開放平臺，依[政府資料開放授權條款第 1 版](https://data.gov.tw/license)使用
- 條碼商品資料：[Open Food Facts](https://world.openfoodfacts.org/)（ODbL），可線上查詢，也可用 `Tools/nutrition` 從官方匯出檔篩出台灣商品內建
- 品牌與常見食品（選用）：`Tools/nutrition` 的程式會從品牌官網、臺北市／新北市食材登錄平台、營養師文章抓取公開的熱量資料，產生 `iOS/Resources/brand_foods.json`；這些資料只放在自己的手機，不放進 GitHub
- 每日目標參考：衛生福利部國民健康署[「國人膳食營養素參考攝取量」第八版](https://www.hpa.gov.tw/Pages/Detail.aspx?nodeid=4248&pid=12285)（熱量、蛋白質、醣類、脂質、鈉、膳食纖維建議量）
- 像素字體：[俐方體 11 號 Cubic 11](https://github.com/ACh-K/Cubic-11)（SIL Open Font License 1.1，授權全文在 `Shared/Fonts/Cubic_11-OFL.txt`）
